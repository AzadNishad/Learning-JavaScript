## 🟢 Easy Level: Get Comfortable

1. **Select and Change Text**
   - Select a `<p>` tag with ID `intro` and change its text to `"Welcome, Suman!"`.

2. **Change Style on Click**
   - When a button is clicked, change the background color of a `<div>` to green.

3. **Toggle Visibility**
   - Create a button that hides and shows a paragraph when clicked.

4. **Add New Element**
   - Add a new `<li>` to an existing `<ul>` when a button is clicked.

5. **Change Image Source**
   - Replace the `src` of an image with a new URL when a button is clicked.

---

## 🟡 Medium Level: Think Dynamically

6. **Build a To-Do List**
   - Create a form that adds tasks to a list. Each task should have a delete button.

7. **Live Character Counter**
   - Show the number of characters typed in a `<textarea>` in real-time.

8. **Form Validation**
   - Prevent form submission if any required field is empty and show an error message.

9. **Accordion Menu**
   - Clicking a section header should expand/collapse its content.

10. **Dynamic Table**
   - Create a table where rows can be added or removed dynamically.

---

## 🔴 Hard Level: DOM Mastery

11. **Drag and Drop**
   - Implement drag-and-drop functionality between two containers.

12. **Custom Modal**
   - Build a modal popup that opens on button click and closes when clicking outside or pressing ESC.

13. **Virtual DOM Simulation**
   - Create a simple virtual DOM diffing mechanism that updates only changed elements.

14. **Dynamic Form Builder**
   - Let users add input fields dynamically and collect all values on submit.

15. **DOM Mutation Observer**
   - Use `MutationObserver` to detect when new elements are added to a specific container.
